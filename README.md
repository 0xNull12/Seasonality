# Seasonality
**Note: This mod will be updated very slowly**

Seasonality implements the four seasons (spring, summer, fall, and winter) in Minecraft 1.12.2. Although it shares a similar concept with Serene Seasons, it has been completely rewritten from scratch under an open-source license to add new features, fix bugs, and keep it up to date

The mod’s logic has been fully replicated and works flawlessly (except for a few beta bugs that are currently being fixed and will be resolved)

## Features
* **Performance comes first (at least for me):** Most of the code has been optimized not all of it, but the majority.
* **Snow recalculation:** Calculates seasonal effects, such as winter leaving snow behind when the chunk loads in the middle of summer, similar to Serene Tweaks.
* **Dynamic planetary rotation:** Subtle (almost imperceptible) variations in the length of the day-night cycle depending on the current season, simulating Earth’s orbital tilt (though I’m no scientist I just Googled it)

**About the license**: This mod specifically the final `.jar` file and the source code does not distribute any texture files or code from Serene Seasons, as it is up to the user to download the textures to their computer from the original repository and decide whether to play without textures or with the Serene Seasons textures

**Regarding compatibility with other mods**: There isn’t any yet, since this is a complete rewrite from scratch, but full compatibility will be available soon. It’s currently in development, but I’ve managed to make it compatible with SimpleDifficulty though I don’t know if it works with other mods
